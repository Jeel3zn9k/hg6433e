# «Табло — пульт» — Android-приложение (версия 1.0, 2026-11)

Клиент веб-панели хоккейного табло для телефонов/планшетов на **Android 8.0 (API 26) и новее**.
Приложение построено с нуля по принципу «надёжная оболочка»: весь матч-логика живёт
на машине табло (Tablo.exe, веб-сервер порт 8642), а приложение показывает ту же
веб-панель, что и браузер ПК, — поведение 1:1, никаких вторых копий логики.

## Что умеет
- **Три вида** (меню → «Вид…»): телефонный пульт `/panel` (крупные кнопки),
  панель оператора `/operator` (вид с ПК), витрина `/display` (только табло).
- **Адрес сервера** задаётся в меню (по умолчанию `http://192.168.1.50:8642`).
- **«Запомнить вход»** работает: токен сессии хранится в localStorage WebView
  и переживает перезапуск приложения.
- **Экран всегда включён** (по умолчанию вкл., отключается в меню) — телефон
  не гаснет во время матча.
- Сессия **не рвётся** при переходе телефона между Wi-Fi и мобильной сетью
  (серверная правка О-7: сессия привязана к токену, а не к IP).
- Понятный экран «Нет связи с табло» с подсказками и кнопкой «Повторить».

## Доступ только для своих
Приложение не содержит никаких «своих» паролей и не публикуется в магазинах:
- APK передаётся только знакомым людям лично;
- подключение возможно лишь к вашему серверу в вашей сети;
- вход — по паролю оператора веб-панели (задаётся в «Режим разработчика»);
- на сервере действуют прежние ограничения: не более 2 устройств одновременно,
  выход по простою (30 мин) и абсолютному сроку сессии (8 ч), нарастающая пауза
  после неудачных попыток входа.

## Сборка APK

### Вариант 1 — Android Studio (проще всего)
1. Установите Android Studio (версия Hedgehog 2023.1.1 или новее) — она сама
   скачает Gradle, Android SDK 34 и JDK 17.
2. `File → Open…` → выберите папку `android/` → Open. Дождитесь окончания
   синхронизации Gradle (внизу экрана).
3. **Отладочный APK** (ставится на телефон без подписных настроек):
   `Build → Build Bundle(s)/APK(s) → Build APK(s)`.
   Файл: `app/build/outputs/apk/debug/app-debug.apk`.
4. **Подписанный релизный APK** (для постоянной раздачи):
   `Build → Generate Signed Bundle/APK… → APK → Create new…` (кейсохраните
   в надёжном месте) → вариант release. Файл появится в
   `app/build/outputs/apk/release/`.

### Вариант 2 — командная строка (без Android Studio)
Нужны: JDK 17, Android SDK (platform 34, build-tools), переменная `ANDROID_HOME`.
В файле `local.properties` (создать рядом с `settings.gradle`) укажите:
`sdk.dir=/путь/к/android-sdk`
Затем в папке `android/`:
```
gradle wrapper --gradle-version 8.4     # один раз, создаст gradlew
./gradlew assembleDebug                 # Windows: gradlew.bat assembleDebug
```
APK: `app/build/outputs/apk/debug/app-debug.apk`.

> Обёртка Gradle (`gradlew`) в репозитории не лежит — `gradle-wrapper.jar`
> это бинарник, он создаётся командой `gradle wrapper` или самой Android Studio.

## Установка на телефон
1. Скопируйте APK на телефон (USB, облако, мессенджер — как удобно).
2. Откройте файл — система попросит разрешить «Установку из неизвестных
   источников» для браузера/проводника — разрешите.
3. Установите, запустите «Табло — пульт».
4. Меню (три точки справа вверху) → «Адрес сервера…» → введите IP компьютера
   табло и порт 8642 → OK.
5. Введите пароль оператора веб-панели — можно поставить галочку «Запомнить».

## Подготовка на машине табло
1. «Настройки → Режим разработчика» → включить веб-сервер, задать пароль
   оператора → «Применить».
2. Убедитесь, что брандмауэр Windows пропускает входящие TCP на порт 8642
   для локальной сети.
3. Телефон и компьютер должны быть в одной сети (один Wi-Fi-роутер).

## Технические решения (коротко)
- **WebView, а не нативный UI**: панель уже прошла обкатку на матчах; один и тот
  же HTML/JS обслуживает ПК и телефон — правки сервера автоматически попадают
  в приложение без его переустановки.
- **Кэш WebView отключён** (`LOAD_NO_CACHE`): страница при запуске берётся свежая.
- **Поворот экрана не перезагружает панель** (`configChanges` в манифесте).
- **User-Agent** содержит метку `TabloAndroid/1.0` — устройство видно в журнале
  сервера и в списке сессий окна разработчика.
- SDK-зависимостей минимум: только AndroidX AppCompat; никаких аналитик,
  рекламы и внешних сервисов — приложение работает исключительно с вашей ЛВС.
